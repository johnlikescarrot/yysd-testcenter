# Khu học tập / Luyện Ngữ pháp

**Chỉ cần đặt tệp HTML «Đề học Ngữ pháp» vào thư mục này, hệ thống sẽ tự động phân loại.**

- Phân khu: 📚 Khu học tập (study)
- Kỹ năng: Ngữ pháp (grammar)
- Cách tải lên (upload): Trong thư mục này, nhấp `Add file` → `Upload files` → kéo tệp HTML vào → nhấp `Commit changes`.
- Sau khoảng 1 phút, bài học sẽ tự động hiển thị trong danh mục tương ứng trên trang web, không cần thao tác gì thêm.
