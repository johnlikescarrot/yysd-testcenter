# Khu thi thử / Thi thử TOEFL

**Chỉ cần đặt tệp HTML «Đề thi thử TOEFL» vào thư mục này, hệ thống sẽ tự động phân loại.**

- Phân khu: 🎯 Khu thi thử (mock)
- Kỹ năng: TOEFL (toefl)
- Cách tải lên (upload): Trong thư mục này, nhấp `Add file` → `Upload files` → kéo tệp HTML vào → nhấp `Commit changes`.
- Sau khoảng 1 phút, đề thi sẽ tự động hiển thị trong danh mục tương ứng trên trang web, không cần thao tác gì thêm.
