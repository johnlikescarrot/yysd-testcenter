# Mẫu soạn từ vựng cho giáo viên

Sao chép mẫu [thẻ từ](word-cards.html), [bài kiểm tra](word-quiz.html) hoặc [danh sách](word-list.html), rồi điền `wordData`. Đây là công cụ soạn thảo, không phải đề học viên. Chỉ đưa bài hoàn chỉnh vào `library/study/vocab/` sau khi kiểm tra `python3 scripts/verify_vocab_wrongword_hooks.py` thành công.
